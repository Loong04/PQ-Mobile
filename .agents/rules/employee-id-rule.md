# Employee ID Display Rule

- Whenever displaying an Employee ID (`empNo` / `employee id`) in UI lists, cards, or summaries:
  - Always place it directly **BELOW** the employee's name.
  - Always format it as `#xxxxx` (prefixed with `#`, e.g. `#EBB01`, `#004177`, `#0000101`).
  - Use muted text styling (`color: var(--text-muted); opacity: 0.8; font-family: monospace, sans-serif; font-size: 11.5px;`).
